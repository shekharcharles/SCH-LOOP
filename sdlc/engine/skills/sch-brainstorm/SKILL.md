# Brainstorm

Use when the problem or solution is still uncertain. Inspect repository truth first. Ask only decisions repository inspection cannot answer. Produce `.sch-loop/discovery/brief.md` with outcome, users, workflows, constraints, failure cases, assumptions, exclusions, unresolved decisions and candidate directions. This artifact informs but does not authorize build.
